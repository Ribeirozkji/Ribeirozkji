# Pedro Henrique Ribeiro

Estudante de Análise e Desenvolvimento de Sistemas e desenvolvedor Full-Stack em formação.

Este perfil do GitHub é destinado principalmente a **atividades acadêmicas, estudos, experimentos e projetos pessoais**. Utilizo os repositórios para praticar conceitos de desenvolvimento de software, testar tecnologias, documentar meu aprendizado e acompanhar minha evolução como desenvolvedor.

Tenho foco em desenvolvimento web, especialmente com **JavaScript, React, Node.js e bancos de dados relacionais**. Durante meus estudos, também exploro conceitos de APIs REST, arquitetura de aplicações, Git, segurança da informação e infraestrutura.

Os projetos publicados aqui representam diferentes etapas do meu aprendizado e podem conter experimentações, versões incompletas ou implementações desenvolvidas exclusivamente para fins de estudo.

Atualmente, estou direcionando meus estudos para **desenvolvimento backend e Full-Stack**, buscando construir uma base sólida de programação e desenvolver projetos cada vez mais completos e bem estruturados.

## Projetos de estudo

Os projetos abaixo fazem parte do meu processo de aprendizado. Alguns são atividades acadêmicas, enquanto outros foram desenvolvidos por iniciativa própria para praticar determinados conceitos.

### ProjectFlow

Aplicação web criada como projeto de estudo para praticar organização de tarefas, dashboards e interfaces interativas.

**Tecnologias:** React, JavaScript, HTML, CSS e Git.

**Conceitos praticados:**

* Componentização.
* Manipulação de estado.
* Organização de funcionalidades.
* Construção de dashboards.
* Estruturação de interfaces.

---

### AquaLimpaOFC

Projeto web desenvolvido para estudar criação de páginas informativas, responsividade e interação com JavaScript, utilizando como tema a preservação da água e sustentabilidade.

**Tecnologias:** HTML, CSS e JavaScript.

**Conceitos praticados:**

* HTML semântico.
* Responsividade.
* JavaScript no front-end.
* Organização visual.
* Estruturação de páginas web.

---

### ConectaTudo

Projeto desenvolvido para praticar TypeScript, organização de código, componentes e estruturação de uma aplicação front-end.

**Tecnologias:** TypeScript, JavaScript, HTML, CSS e Git.

**Conceitos praticados:**

* Tipagem estática.
* Organização de código.
* Componentização.
* Separação de responsabilidades.
* Manutenção de projetos.
