## Projetos principais

### ProjectFlow

Aplicação web de gestão de projetos criada para praticar organização de tarefas, controle visual de progresso e construção de interfaces funcionais. O projeto trabalha conceitos como linha do tempo interativa, modo foco gamificado e dashboard de produtividade.

**Tecnologias:** React, JavaScript, HTML, CSS e Git.

**Principais aprendizados:**

- Componentização de interfaces.
- Manipulação de estado.
- Organização de funcionalidades.
- Estruturação visual de dashboards.
- Construção de fluxo de produtividade para usuários.

**Melhorias planejadas:**

- Adicionar autenticação de usuários.
- Criar integração com back-end.
- Persistir dados em banco de dados.
- Publicar versão em deploy.
- Adicionar documentação técnica completa.

### AquaLimpaOFC

Projeto web voltado à conscientização sobre preservação da água e sustentabilidade. A aplicação apresenta informações, recursos visuais e estrutura de página para comunicar boas práticas ambientais de forma acessível.

**Tecnologias:** HTML, CSS e JavaScript.

**Principais aprendizados:**

- Estruturação semântica de páginas.
- Responsividade.
- Organização visual.
- Comunicação de conteúdo em ambiente web.
- Criação de páginas informativas com foco social.

**Melhorias planejadas:**

- Criar uma calculadora de consumo de água.
- Adicionar quiz interativo sobre sustentabilidade.
- Publicar o projeto com GitHub Pages ou Vercel.
- Melhorar acessibilidade e responsividade.
