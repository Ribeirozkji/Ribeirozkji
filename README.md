## Projetos principais

### ProjectFlow
Aplicação web de gestão de projetos com linha do tempo interativa, modo foco gamificado e dashboard de produtividade. O projeto foi desenvolvido para praticar organização de tarefas, controle visual de progresso e construção de interfaces funcionais.

**Tecnologias:** React, JavaScript, HTML, CSS e Git  
**Principais aprendizados:** componentização, organização de interface, manipulação de estado e estruturação de funcionalidades.

### AquaLimpaOFC
Projeto web voltado à conscientização sobre preservação da água e sustentabilidade. A aplicação apresenta informações, recursos visuais e estrutura de página para comunicar boas práticas ambientais de forma acessível.

**Tecnologias:** HTML, CSS e JavaScript  
**Principais aprendizados:** estruturação semântica, responsividade, organização visual e comunicação de conteúdo.

### ConectaTudo
Aplicação desenvolvida em TypeScript com foco em organização de funcionalidades e construção de uma interface mais estruturada. O projeto foi criado para praticar tipagem, organização de código e evolução de aplicações web.

**Tecnologias:** TypeScript, JavaScript, HTML, CSS e Git  
**Principais aprendizados:** tipagem, estruturação de projeto, organização de componentes e manutenção de código.
